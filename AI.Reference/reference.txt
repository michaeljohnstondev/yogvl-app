## 🔧 Key Utilities Reference

### **Event Status Utils** (`eventStatus.js`)
```javascript
import { getEventStatus, getStatusColor, isPastEvent, isEventFull } from '../utils/eventUtils';

// Get event status
const status = getEventStatus(event); // 'Upcoming', 'Starting Soon', 'Completed', 'Ended'
const color = getStatusColor(status); // Returns hex color

// Check event state
const isPast = isPastEvent(event);
const isFull = isEventFull(event);
const timeUntil = formatTimeUntilEvent(event); // "2 hours away"
```

### **User Validation Utils** (`eventValidation.js`)
```javascript
import { 
  validateUserCanJoinEvent, 
  getUserEventPermissions,
  getReliabilityWarning 
} from '../utils/eventUtils';

// Check if user can join (reliability checks)
const canJoin = await validateUserCanJoinEvent(userData, event);

// Get user permissions for event
const permissions = getUserEventPermissions(currentUserId, userData, event);
// Returns: { canEdit, canDelete, canManageAttendance, isCreator, isAdmin }

// Get reliability warning info
const warning = getReliabilityWarning(userData);
// Returns: { shouldWarn, level, message, color }
```

### **Form Validation Utils** (`eventFormValidation.js`)
```javascript
import { validateEventForm, formatEventForStorage } from '../utils/eventUtils';

// Validate form data
const validation = validateEventForm({
  title, location, dateSelected, timeSelected, maxGuests, date, time
});

// Format for database storage
const eventData = formatEventForStorage(
  { title, location, details, date, time, maxGuests }, 
  currentUserId
);
```

### **User Metrics Utils** (`userMetrics.js`)
```javascript
import { 
  updateEventCreationMetrics,
  updateEventSubscription,
  getUserEventStats,
  cleanupEventDeletion
} from '../utils/eventUtils';

// Track event creation
await updateEventCreationMetrics(userId, eventId);

// Track event subscription
await updateEventSubscription(userId, eventId);

// Get user statistics
const stats = getUserEventStats(userData);
// Returns: eventsCreated, eventsAttended, noShows, reliabilityScore, etc.

// Clean up after event deletion
await cleanupEventDeletion(eventId, subscriberIds, creatorId);
```

### **Notification Utils** (`notificationUtils.js`)
```javascript
import { 
  processPendingNotifications,
  generateChangeNotificationContent 
} from '../utils/eventUtils';

// Process all pending notifications
const result = await processPendingNotifications();

// Generate notification content
const content = generateChangeNotificationContent(event);
// Returns: { title, body, priority }
```

## 🎨 Design Patterns Used

### **Smart Component Pattern**
- Components detect their own state needs
- Self-contained logic and styling
- Configurable through props

### **Utility-First Architecture**
- Business logic extracted to utilities
- Reusable across components
- Easy to test and maintain

### **Progressive Enhancement**
- Basic functionality first
- Enhanced features added incrementally
- Graceful degradation for missing data

### **User-Centric Design**
- Smart defaults and fallbacks
- Contextual help and guidance
- Respect for user preferences

2. **Use the tips modal** for user guidance
3. **Check permissions** before showing admin actions
4. **Handle loading states** in all components
5. **Provide fallbacks** for missing data
6. **Log important actions** for debugging
